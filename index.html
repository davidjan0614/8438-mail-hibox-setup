hiBox 手機信箱設定

iPhone / Android 一次搞定 · 照著做 3 分鐘完成

⚡
最省事：iPhone 用「一鍵自動設定」 打開 hibox-phone-8438.onrender.com → 填公司信箱 → 照畫面按「允許／安裝」→ 完成。不用抄任何伺服器參數，最快也最不會填錯。

Android 手機請直接用下面的手動步驟（自動設定目前只支援 iPhone）。

📵 別再找 App 了
中華電信原本的「hiBox全能信箱」App 已從 App Store 下架，商店搜不到、舊連結也失效。請用上面的自動設定或下面的手動步驟。

1共用參數（iPhone、Android 都一樣）

項目填入值
收件伺服器
IMAP		 imap.hibox.biz
收件埠號 993　加密：SSL
iPhone：SSL 要「開啟」
寄件伺服器
SMTP		 smtp.hibox.biz
寄件埠號 587　加密：STARTTLS
iPhone：SSL 要「關閉」／Android：選 STARTTLS
帳號 你的完整公司信箱
密碼 你的信箱密碼
⚠️ 兩個數字一定要對
收件 993、寄件 587。寄件填 465 不會通（hiBox 沒開這個埠）。

2iPhone 設定步驟

🍎 用內建「郵件」App
⚠️ iPhone 實測提醒（重要）
iOS 的自動偵測會失敗，不要讓它自己找，一定要走「其他 → 加入郵件帳號」手動填。
每一步都要自己選對，尤其帳號要填完整信箱、收件 SSL 要開、寄件 SSL 要關。
  1. 開啟 設定 → 往下找到 郵件
  2. 點 帳號 → 加入帳號
  3. 選最下面的 其他 → 點 加入郵件帳號
  4. 填「電子郵件」= 公司信箱、「密碼」= 信箱密碼 → 下一步
  5. 選 IMAP，收件伺服器填 imap.hibox.biz、埠 993，把 SSL 打開
  6. 寄件伺服器填 smtp.hibox.biz、埠 587，SSL 保持關閉（不要打開）
  7. 右上角 儲存 → 完成
🔑 最關鍵的一步：寄件 SSL 要「關閉」
iOS 沒有「STARTTLS」這個選項，只有一個「SSL」開關。收件(993) 開、寄件(587) 關——寄件若把 SSL 打開，會變成直接對 587 硬加密，握手失敗，結果就是能收信、寄不出去。

3Android 設定步驟

🤖 用 Gmail App（或手機內建 Email）
  1. 開啟 Gmail → 右上角頭像 → 新增其他帳號
  2. 帳號類型選 其他（Other）
  3. 輸入公司信箱 → 選 IMAP（不要選 POP3）
  4. 密碼填信箱密碼
  5. 收件伺服器 imap.hibox.biz／埠 993／安全類型 SSL
  6. 寄件伺服器 smtp.hibox.biz／埠 587／安全類型 STARTTLS
  7. 點 下一步 → 完成
小提醒：若出現「憑證／安全性警告」，選 接受 即可。

4常見問題排除

我們以前用 mailsvr.persee.com.tw，現在還能用嗎？

不行了。切換到 hiBox 後，舊的 mailsvr.persee.com.tw 已經停止收發。手機／電腦一律改成：收件 imap.hibox.biz（993 SSL）、寄件 smtp.hibox.biz（587 STARTTLS）。舊設定留著會出現「連不上伺服器」。

可以收信，但寄不出去

九成是寄件埠或加密設定錯。寄件一定要 smtp.hibox.biz、埠 587：
• iPhone：SSL 要關閉（開著會握手失敗，寄不出去）
• Android：安全類型選 STARTTLS
改成 465 也會失敗（hiBox 沒開這個埠）。

一直跳出「密碼錯誤」

請確認：① 帳號要填完整信箱（不是只填前面的名字）② 大小寫要對 ③ 若近期改過密碼，手機要重新輸入。仍不行請找 MIS 確認帳號狀態。

完全收不到新信

先確認電腦的 Webmail 收得到（代表伺服器正常）。若 Webmail 有信、手機沒有，通常是手機設定選成了 POP3，請改用 IMAP。

要選 IMAP 還是 POP3？

選 IMAP。信件會留在伺服器，手機、電腦、Webmail 看到的都一樣。POP3 會把信抓到單一裝置，容易發生「這台有、那台沒有」。

hiBox 的 App 還能下載嗎？

已經沒有了。中華電信原本的「hiBox全能信箱」App 已從 App Store 下架，商店搜不到、舊連結也失效（這是很多人卡住的原因）。iPhone 請用最上面的一鍵自動設定，或用本篇手動設定；Android 請照手動步驟。
